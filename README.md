# NavMesh Parkour

Багаторівнева локація в Unity 6, де ШІ-охоронець сам застрибує на платформи-вежі та зістрибує з них, щоб дістатися до наступної точки маршруту.

## Що робить проєкт

- основна площина та три платформи-вежі різної висоти (3, 4 і 6 метрів);
- охоронець патрулює 6 точок: частина на землі, частина на вершинах веж;
- шлях між землею і вежами будується через NavMesh Link, а стрибок виконується по параболі.

## Механіки NavMesh

- NavMesh Surface — запечена навігаційна сітка для землі та верхівок веж;
- NavMesh Link (bidirectional) — зв'язок земля ↔ вежа в обидва боки;
- NavMesh Agent з autoTraverseOffMeshLink = false;
- AgentJumper — власний скрипт стрибка по параболі з CompleteOffMeshLink();
- WaypointPatrol — циклічний обхід точок маршруту.
